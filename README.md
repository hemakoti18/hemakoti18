## Selected work

### AttendEase · Student attendance portal

Our team built a browser app for teachers taking roll call. A teacher can choose a date, search by name or roll number, correct a mark and export the day's register to CSV. Records stay in the browser's `localStorage` between visits.

One detail matters during roll call. A student can be **present**, **absent** or **unmarked**. If 8 are present, 2 absent and 5 unmarked, the dashboard shows **80% present among the 10 marked students**. The teacher can see which names still need a mark.

### Food delivery profitability · Analytics practice

**Orders went up. Did each order earn more?** I compare profit per order with delivery cost per order in a monthly dataset. If profit per order falls while delivery cost per order rises, I'd ask for order-level data by route and basket size to see where margins changed.
